# 💚 Care Companion

### Your Care. Your Language. Your Community.

**Care Companion** is an AI-powered iOS application that helps individuals and families discover healthcare services, educational opportunities, emergency assistance, and essential community resources.

Built with **SwiftUI, Supabase, OpenAI, and Apple MapKit**, Care Companion aims to make essential support more accessible across different languages and communities.

## 🌍 Our Mission

To connect people with the care, information, and community resources they need, regardless of their language, background, or location.

## ❗ The Problem

Finding reliable community resources can be difficult, especially for people who are new to an area, face language barriers, or need urgent assistance.

Information about hospitals, shelters, schools, food assistance, and family services is often spread across multiple platforms.

**Care Companion brings these resources together into one accessible experience.**

## 🚀 Getting Started

### Prerequisites

- macOS
- Xcode
- An iOS simulator or compatible iPhone
- Supabase project configuration
- Access to the required backend services

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Briankipkorir/CareCompanion.git
```

**2. Open the project folder**

```bash
cd CareCompanion
```

**3. Open the Xcode project**

Open `CareCompanion.xcodeproj`.

**4. Configure the backend**

Set up the required Supabase configuration and Edge Functions.

Never commit private API keys, service-role credentials, or other secrets.

**5. Run the application**

Select an iPhone simulator in Xcode and press **Run**.
